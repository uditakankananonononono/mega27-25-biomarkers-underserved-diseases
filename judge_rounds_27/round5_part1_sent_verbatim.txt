5.3 What the split comparison does and does not show
The arithmetic mean AUROC is 0.98044 random versus 0.59123 family-held-out, difference 0.38921. This is a
reproducible broken-benchmark finding: random-split keyword performance does not transfer cleanly to
annotated unseen protein families under this model and task. Class composition differs by held-out family; the
gap is descriptive, not an isolated causal measure of homology leakage. Unmeasured cross-family sequence
resemblance and curation bias remain possible. Baseline prevalence is fold-specific, so AP should always be read
alongside positive count and baseline AP.

9. PhosGene: coding-sequence arithmetic and physiology gap
GenBank U00096.3 resolves the AppA CDS and translation corresponding to UniProt P07102. The older M58708
CDS has an ambiguous base at one codon; the K-12 genome provides a resolved codon with the same translated
amino acid. The Kazusa taxon 83333 codon table has 64 codon entries based on only 14 coding sequences and
5,122 codons, so its reference weights are sparse. The optimizer replaces each amino acid codon with the highest-
frequency synonymous codon and retains a terminal stop. It checks translation identity and input bounds. No
construct was synthesized or tested for host expression.
                  w(c | a) = observed_count(c) / max_{synonymous c* encoding a} observed_count(c*).
                          CAI(sequence) = exp[(1/L) sum_{i=1}^{L} log w(c_i | amino_acid_i)].
Observed AppA CAI is 0.610734 against the sparse table; the unrestricted maximum is 1.0 by construction. A

GC-window constraints, repeat filtering and host-specific secretory regulation are not supported in the current
