5. VenomFunction-2: task, entries, split design
We retrieved 2,068 reviewed Swiss-Prot snake-toxin search rows in five bulk pages. The task label is UniProt
Neurotoxin keyword, not measured potency, clinical benefit, receptor binding or an experiment. The family is a
UniProt similarity-comment family annotation. Sequences shorter than 25 residues, unnamed-family records and
exact duplicates were excluded; one exact-sequence conflicting-label group was removed as ambiguous. The final
training/evaluation corpus has 1,814 unique sequences, 542 keyword positives, across 25 named family groups.
Bulk IDs alone do not count toward the strict individual-accession gate.
The classifier is a binary character 3-mer CountVectorizer with min_df=2 and balanced logistic regression.
Vocabulary is fitted only on the training fold. A prevalence-only dummy baseline is refit per fold. Five random
stratified folds are compared with five disjoint family folds; these are different target populations and not
interchangeable matched samples. A large random-fold AUROC can arise from homologous motifs shared across
train and test; measured 3-mer overlap is audited below.
                               x_s[k] = 1 if protein sequence s contains amino-acid 3-mer k, else 0.
                                     p(y=1 | x) = 1 / (1 + exp[-(beta_0 + sum_k beta_k x_k)]).
                           L(beta) = sum_i w_i[-y_i log(p_i) - (1-y_i) log(1-p_i)] + lambda ||beta||_2^2.
                                 AUROC = P(score(x_positive) > score(x_negative)) + 0.5 P(tie).
                              AP = sum over recall steps j of (Recall_j - Recall_(j-1)) * Precision_j.
                            Gap = mean(random-fold AUROC) - mean(disjoint-family-fold AUROC).

5.3 What the split comparison does and does not show
The arithmetic mean AUROC is 0.98044 random versus 0.59123 family-held-out, difference 0.38921. This is a
reproducible broken-benchmark finding: random-split keyword performance does not transfer cleanly to
annotated unseen protein families under this model and task. Class composition differs by held-out family; the
gap is descriptive, not an isolated causal measure of homology leakage. Unmeasured cross-family sequence
resemblance and curation bias remain possible. Baseline prevalence is fold-specific, so AP should always be read
alongside positive count and baseline AP.

5.4 Follow-up: measured sequence-similarity exposure
After the frozen benchmark, a separate follow-up measured whether test proteins actually resemble proteins
available for training. In each original fold, the method forms the set of contiguous three-amino-acid substrings
for every test and training sequence, computes pairwise Jaccard similarity, and retains the maximum training
match for each test record. Unlike a model score, this overlap has no fitted label coefficients. The local analysis
plan was written in the same session just before this computation; it is not independent preregistration, and the
original AUROC difference was already known.
                    Jaccard(s,t) = |three_mers(s) intersect three_mers(t)| / |three_mers(s) union three_mers(t)|.
                              Maximum exposure(s, train_fold) = max_{t in train_fold} Jaccard(s,t).

Random-fold test proteins have mean max Jaccard 0.6210 to a training protein; 33.5% have a match >=0.80.
Family-held-out test proteins have mean max 0.0442 and none >=0.80. This documents a large similarity
exposure difference, which makes the high random AUROC less persuasive as evidence for a novel-family use
case. It does not isolate a causal leakage effect: group composition and label prevalence differ; threshold 0.80 was
a fixed descriptive cutoff, not a biological homology definition. Fold-specific metrics and source code are in
venom/data/similarity_leakage.json and venom/scripts/similarity_leakage.py.
