6. Individually fetched accession audit
To meet a stricter unit of biological data, venom/scripts/validate_individual.py issued 120 separate direct
UniProtKB entry reads. Each saved JSON records accession, sequence and source URL, compared with the bulk
snapshot. We selected 60 three-finger toxin and 60 phospholipase A2 records, each group 30 keyword-positive
and 30 keyword-negative after deduplication. No held-out accession enters training; individual_validation.py
produced a prediction from each individually fetched sequence. The selection is balanced by construction and
uses the same UniProt source, so it is not a new natural-prevalence or external experimental cohort.
phospholipase a2: n=60, positives=30, AUROC=0.60667, AP=0.58658, prevalence-only AP=0.500. Do not read
the two family scores as a pooled clinical metric.
three-finger toxin: n=60, positives=30, AUROC=0.42667, AP=0.48640, prevalence-only AP=0.500. Do not read
the two family scores as a pooled clinical metric.
        Per-accession audit inclusion = direct entry GET AND identity/sequence validation AND an actual held-out score.
The 120 one-to-one source records are named in venom/data/individually_validated_120.tsv; the scored
probabilities, labels, family and URLs are in venom/data/individual_validation.json. Appendix A tabulates all 120
scores. Three-finger AUROC below 0.5 in the balanced sample is a negative result, not a reason to invert labels
after seeing the answer.

6.0 Post-hoc family annotation control
On the same five random folds, a model given only the UniProt similarity-comment family label achieved mean
AUROC 0.87929, compared with 0.98044 for the sequence 3-mer model. The family feature is an annotation, not
a sequence-derived predictor. The encoder is fit only on each training fold, but both label and feature come from
UniProt. This post-hoc control diagnoses annotation structure, not a causal decomposition of the sequence model
or a fix for held-out-family failure. Frozen local diagnostic plan, code and results:
protocols/venom_family_annotation_diagnostic_2026-09-25.md, venom/scripts/family_annotation_control.py,
venom/data/family_annotation_control.json.

6.2 Threshold transfer without target-label tuning: another negative
A separate exploratory attempt asked whether a decision threshold learned outside both target families could
recover positives without reusing target labels. The model was trained on 951 sequences from 23 other families.
Five GroupKFold out-of-fold predictions over those training families supplied a single scalar threshold that
maximized balanced accuracy. The previously scored 120 direct-entry target proteins were not used to choose this
threshold. However, the target outcomes were already visible before this experiment was planned, so it is not
independent prospective validation.
The selected training-family threshold was 0.001159, with training-family out-of-fold balanced accuracy 0.5227.
It is far below 0.5, already warning of severe distribution shift. On each of the two balanced target groups, the
original 0.5 threshold gave 30 true negatives and 30 false negatives. The non-target-calibrated threshold gave 30
true positives and 30 false positives. Both achieve balanced accuracy 0.5 by predicting one class for all records.
Thus this threshold transfer did not repair the actual decision problem. It cannot be reselected on target labels after
seeing this result without sacrificing holdout integrity.

This jointly excluded both target families during model fitting, whereas the original direct-entry scoring excluded

6.3 Within-project label-coherence check
A second VenomFunction pivot checks a narrow data-quality explanation without redefining the original held-out
negative. Registered thresholds 1.00 and 0.95 positional identity before this scan; only equal-length raw direct-
entry sequences are comparable by this proxy. The scanner reads the same 120 saved direct-UniProt entry JSON
files and lists accession pairs with their keyword, source URLs, family and identity. This is not a new cohort or an
optimized classifier.
Across 120 direct entries, 277 pairs had equal lengths; 21 had at least 95% positional identity, and 0 of those had
discordant keyword labels. At exact identity, 0 pairs were found. Thus the high-identity equal-length subset does
not reveal a direct internal keyword contradiction in this sample. Unequal-length sequences were not aligned;
other annotations, nearly identical proteins outside this 120-entry selection, and true functional outcomes remain
untested. File: venom/data/label_conflict_audit.json, method: venom/scripts/label_conflicts.py.
