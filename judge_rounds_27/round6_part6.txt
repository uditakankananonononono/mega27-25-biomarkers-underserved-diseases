12. Reproduction and responsible claims
Install project dependencies, then run PYTHONPATH=src:. python -m pytest -q. Rebuild award list with python
survey/scripts/collect_awards.py, toxin bulk source with python venom/scripts/fetch_uniprot.py, evaluation with
OPENBLAS_NUM_THREADS=1 python venom/scripts/evaluate.py, active-site test with PYTHONPATH=src:.
python -m venom.scripts.audit_active_sites, and direct-entry audit with PYTHONPATH=src:. python -m
venom.scripts.validate_individual followed by python -m venom.scripts.individual_validation. Fetch AppA and
codon reference with python phosgene/scripts/fetch_reference.py and run PYTHONPATH=src:. python -m
phosgene. Live endpoints can evolve, so committed result JSON and dated URLs are the result provenance; re-
runs must compare source IDs, labels and sequences, not assume unchanged annotations.
Safety and scope: toxin analyses compare public sequences and database keywords and do not supply a biological
construction protocol or claim clinical deployment. The codon optimization is a computational arithmetic
demonstration, with no synthesized construct, animal study, medical recommendation, or environmental release.
The result is a usable benchmark/rubric/sandbox at their stated bounded scopes, not world-best potency prediction
or a validated pig system.
