!Sample_data_processing = For RNAseq analysis, raw RNA-seq reads were assessed with FastQC and MultiQC, trimmed for adapters and low-quality bases using BBDuk (BBMap), and re-evaluated for quality. Clean paired-end reads were aligned to the human GRCh38 reference genome using HISAT2, followed by SAM sorting with samtools and duplicate marking with Picard. Alignment quality and gene body coverage were examined using Qualimap RNA-seq. Gene-level quantification was performed with featureCounts (Subread). Differential gene expression analysis was performed using DESeq2. Spatial transcriptomics data were processed in R using Seurat. Spaceranger output files were imported with Load10X_Spatial, retaining only tissue-associated spots. Quality metrics (e.g., spot UMI counts) were inspected by violin and spatial feature plots. Each sample was normalized using SCTransform to correct for sequencing depth and technical variation. Datasets were merged into a single Seurat object, and variable features were used for PCA, nearest-neighbor graph construction, Louvain clustering, and UMAP visualization. Batch effects between samples were corrected using Harmony. Spatial cluster identities were visualized with SpatialDimPlot, and cluster-specific marker genes were identified using FindMarkers after PrepSCTFindMarkers normalization. Region-level annotations (e.g., trophoblasts, secondary villi) were added to the metadata based on cluster membership. For differential expression, raw count matrices from the Spatial assay were used to construct DESeq2 objects with sample condition as the design variable. Differentially expressed genes were extracted, filtered by adjusted p-value and fold change, and exported for visualization and downstream interpretation.
