# Shared-core identifier units, September 27, 2026

`python3 scripts/audit_manifest_units.py` reads the committed `results/dataset_manifest.csv` and the older `results/gsm_to_study.csv`. It asserts unique accession IDs, checks all old mappings are in the manifest, infers only the 180 newly included GSM mappings from explicit GSE roles (and the documented GSE28242 P7 series crosswalk), and emits `results/gsm_to_study_complete.csv`. It does not fetch or analyze expression.

Current manifest has **1,509 distinct records**, including **1,382 GSM specimen identifiers**, **90 GSE series identifiers**, **26 GPL platforms**, and **11 ontology/network metadata identifiers**. The old 1,202-row map was stale by 180 GSMs added September 25-26; this explains the old paper's 1,328 total exactly. The completed map has 1,382 GSM-to-GSE edges referencing 43 parent GSE series; these 43 are represented by specimens in the manifest, not 43 new studies in addition to the 90 GSE IDs. GSE127831 (28 used leishmaniasis GSMs) has now been added as one used parent accession: the P35 frozen protocol, normalized matrix/design SHA-256s, full per-GSM source crosswalk, and result script in commit `8c107c2` document its actual use. The source is https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE127831; a current web-fetch attempt returned SOURCE_NOT_AVAILABLE, so the audit relies on the committed source bytes plus an accessible metadata mirror at https://www.omicsdi.org/dataset/geo/GSE127831. This accession adds no new cohort or subject. The other 47 GSE identifiers have no GSM mapping here, and an accession row alone cannot say if each represents an independent study or deduplicated reuse.

Counts are IDs, not people, independent cohorts or genuine external-service uses. Some GSMs are repeated libraries or paired samples; the study's independent participant count needs a separate disease-specific audit. The old prose's 1,328/1,202 was accurate for the older map snapshot but no longer matches the committed manifest and must not be presented as a current count.
