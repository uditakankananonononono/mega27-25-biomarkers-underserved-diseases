!Sample_extract_protocol_ch1 = RNA was extracted from lipid biopsy samples using the RNeasy Lipid Tissue Mini Kit (cat. no. 74804), with a combination of a Qiagen TissueRuptor (Cat No. 9001273) and QIAShredder columns (Cat No. 79654) used for tissue homogenisation. After homogenisation each sample was split into two tubes, and a further 0.5ml of QIAzol reagent added to each tube. Each tube was then treated as a separate RNA extraction, following the RNeasy Lipid Tissue Mini Kit protocol as written. Once RNA was eluted the aliquots were recombined to give a final volume of 60ul eluted RNA.
!Sample_extract_protocol_ch1 = All RNA libraries were produced using the Beckman Coulter Biomek FxP (Cat No. A31842) with New England Biolab Ultra Directional RNA Library Prep Kit (Cat No. E7420L) and NEBnext Multiplex Oligos for Illumina Dual Index Primers (Cat No. E7600S), using provided protocols. 100ng of total RNA was used for library construction where possible. However in some cases the extracted RNA was at too low a concentration. For these samples 25ng total RNA was used for library construction. 13 cycles of PCR amplification were carried out upon all libraries of 100ng total RNA, and 15 cycles upon libraries with 25ng input total RNA.
!Sample_data_processing = Bcl results files were converted to fastq using bcl2fastq Conversion Software v1.8.4 (Illumina).
!Sample_data_processing = RNA-seq reads were mapped onto the human genome (hg19, UCSC annotation) using TopHat software v2.1.0 using default parameters with the following exceptions: --library-type fr-firststrand and using the --GTF parameter provide the UCSC hg19 annotation
!Sample_data_processing = BAM files containing the mapping of each read to the genome were sorted using samtools v0.1.19
!Sample_data_processing = Counts per gene were calculated using the htseq-count tool from the HTSeq v0.6.1p1 package with the following parameters: --format=bam –minaqual=1 –stranded=reverse --mode=intersection_nonempty
!Sample_data_processing = Normalised FPKM values for each gene were calculated using DESeq2 and GenomicFeatures v1.24.4 package from Bioconductor release 3.2. Genes were further standardised via cell transformation. Pathway genes corresponding to adipogenesis, insulin resistance, fatty acid metabolism, lipoprotein and cholesterol metabolism were extracted. Sample types were averaged and genes excluded if there was 0 expression across the compared samples
