!Sample_extract_protocol_ch1 = Total RNA was extracted from eSF or eEC cultures (1 μg of total RNA from each sample) using the High Pure RNA Isolation kit (Roche) according to the manufacturer’s protocol. Quality of isolated RNA was confirmed using Nanodrop for RNA purity (OD 260/280) and Bioanalyzer (Agilent) for RNA integrity. RNA samples with an RNA Integrity Number (RIN) > 6 were used for library preparation for mRNA sequencing.
!Sample_extract_protocol_ch1 = All RNA sequencing (RNAseq) procedures were performed by Novogene. Library preparation was performed using 1 μg of total RNA from each sample with the NEBNext Ultra RNA Library Prep Kit (New England BioLabs, Inc.). Briefly, polyadenylated (polyA) RNAs were selected using NEBNext Magnetic Oligo d(T)25 Beads (New England BioLabs, Inc.). Following polyA selection, RNA was fragmented and primed for first-strand cDNA synthesis, followed by second-strand synthesis. Double stranded cDNA was purified using Agencourt AMPure XP Beads (Beckman Coulter), the fragments were end-repaired, 3' adenylated, and NEBNext Adaptor with hairpin loop structure (Illumina) was ligated to prepare for hybridization. cDNA fragments ~350 bp in length were selected using the Agencourt AMPure XP system (Beckman Coulter) and PCR amplification was performed to create the final cDNA library.
!Sample_extract_protocol_ch1 = Paired-end RNAseq, at >20 million reads per sample was sequenced on an Illumina HiSeq platform (Illumina), per the manufacturer’s instructions.

!Sample_data_processing = Trimmed reads were aligned to the Genome Reference Consortium Human Build 38 reference genome (GenBank Assembly Accession: GCA_000001405.15) using TopHat2 v2.1.0 with the following parameters: global alignment, no mismatch in the 20 base pair seed, up to two mismatches in the read, library type fr – unstranded, and mate inner distance 50. Aligned reads were filtered by removing reads with low mapping quality (below 20) and keeping singletons.
!Sample_data_processing = Filtered reads were annotated to the Genome Reference Consortium Human Build 38 reference transcriptome (RefSeq Assembly Accession: GCF_000001405.26) using the Partek E/M annotation model (Partek Flow, build version 5.0.16.1128) with the following parameters: junction reads required to match introns (set to true), strict paired-end compatibility not required (set to false), and strand specificity not required (set to false). Filtered reads were normalized using TPM (Transcripts Per Kilobase Million). Low expressing transcripts were removed, with lowest maximum coverage set to 1.0.
!Sample_data_processing = Differential gene expression was calculated by ANOVA in a paired test (paired on donor ID), by using treatment as the fixed factor and ID as the random factor. Differentially expressed transcripts were identified based on fold change (³ ± 1.5), with significance level set at P < 0.05.
