The source crosswalks carry exact primary GEO source URLs, SHA256 of each quick SOFT response, series title and digest, platform, phenotype and person token. The GSE335141 matrix headers use array position codes rather than GSMs; each `matrix_column` was independently recovered from that GSM's `!Sample_description` and checked against the matrix. The complete public matrices were downloaded and hashed, but not stored in git due to size. Exact URL and SHA256 appear in each JSON summary. Run `PPD_GEO_CACHE=/path/with/matrix/downloads python3 projects/postpartum_depression/ppd_methylation_audit.py` to reproduce the screens; the script downloads source matrices automatically if absent. Dependencies: NumPy and SciPy.

The two cohorts differ in platform, draw timing and PPD ascertainment; no pooled meta-analysis, cross-omic inference or classifier benchmark is justified. The smallest unadjusted p-values are not discoveries because each cohort's 0.05 FDR threshold rejects none. The 119 expression libraries from GSE290313 remain a separate patient-identity ambiguity, not 119 proven independent women. Next step: resolve that crosswalk and predeclare a testable endpoint with an external same-modality cohort; keep all null results in the audit ledger.
