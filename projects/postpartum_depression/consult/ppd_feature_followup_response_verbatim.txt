One important implementation rule

For #1–#4, feature selection must happen inside each training fold. For example, selecting the “top CpGs” from all GSE44132 participants and then running LOPO is still leakage. The held-out participant must be completely invisible to every learned preprocessing, selection, and tuning step.

What I would not build yet

I would explicitly not build a new genome-wide gene/CpG discovery engine, deep-learning model, pathway-mining pipeline, or cross-platform classifier at this stage. With the current evidence, those primarily increase degrees of freedom rather than validity.

The GSE335141 dataset is useful for the temporal question, but it cannot repair the missing independent antenatal validation problem. And the GSE44132 platform itself contains 483,266 processed methylation measurements per deposited sample, illustrating why unconstrained feature search is particularly vulnerable to overfitting here. 
NCBI

Hard stop: if a prespecified molecular model fails the patient-level LOPO test or fails to add reproducible information beyond the antenatal baseline, the scientifically correct next step is not another feature search. It is to report the null and identify what additional independently mapped cohort would be required to test whether the finding generalizes.
