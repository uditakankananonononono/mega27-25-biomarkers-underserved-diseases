# Independent prospective PPD methylation source feasibility, metadata only

Decision at 2026-09-26: **NO currently usable independent public patient-level cohort verified for this exact two-CpG prospective experiment. Stop the positive experiment.** This is a feasibility verdict from inspected primary metadata, not proof no such cohort exists anywhere. No new methylation/expression values were read for this audit and no model was rerun. The GSE44132 internal LOPO number (0.757) is an artifact-sensitive historical-cohort exploratory figure, not a target, pass or validation result.

## Required for an eligible source

Independent patient cohort with prenatal/pre-symptom blood methylation; later adjudicated postpartum *diagnosis* (not just symptom cutoff); cg21326881 and cg00058938 measured or an independently justified assay map before values are examined; prenatal mood strata and a measured clinical baseline; public/source-authorized patient-level identifiers linking timing, outcome, mood and both assays. A publication-level performance claim without accessible per-person data is not usable for our independent test.

NCBI GEO targeted queries for `"postpartum depression" AND "methylation" AND gse[ETYP]` returned only GSE335141 and GSE44132 on the date of this audit. A broader `depressive symptoms pregnancy methylation` query surfaced GSE311619 but not an eligible postpartum endpoint. Search coverage is incomplete, so this is a negative feasibility check under current public sources, not a universal absence assertion.

## Stop rule and path to unblocking

No new performance prereg, baseline tuning or data-driven feature search in this PPD lane. The only potentially useful next source work is a source-approved per-person dataset release or collaboration providing prenatal methylation at the two defined CpGs, prior mood/clinical covariates and later adjudicated PPD diagnosis. If only EPDS symptoms are available, the research question must be explicitly changed and independently preregistered by the owner; it cannot be silently relabeled diagnosis. If no such source is available, stop PPD positive experiment and redirect to another lane. All earlier null screens and the internal LOPO artifact remain in their original ledgers.
